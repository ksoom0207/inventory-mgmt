# 재고 집계 기준

## 기본 원칙

Site는 자산의 위치를 구분하는 축이다. 같은 Site 안에서도 부품 유형과 주요 사양이 다르면 별도 재고 그룹으로 집계한다. `size`라는 단일 항목 대신 용량, 물리적 크기, 속도, 인터페이스를 구분한다.

개별 자산은 자산 ID로 유지하며 그룹은 조회 시 계산한다. 사양을 수정하거나 Site를 이동하면 다음 조회부터 새 그룹에 반영한다. Serial은 개별 식별자이므로 집계 키에 포함하지 않는다. P/N은 정확한 교체 부품을 찾는 기준이며, 사양이 같다는 이유만으로 교체 호환성을 보장하지 않는다.

## 유형별 권장 기준

| 유형 | 권장 집계 키 | 추가 구분·조회 후보 | 도입 상태 |
|---|---|---|---|
| SSD | 용량 + 인터페이스 + 폼팩터 | P/N, 내구도, 섹터 규격 | 적용 |
| HDD | 용량 + 인터페이스 + 폼팩터 | RPM, 섹터 규격, P/N | 적용 |
| 메모리 | 용량 + DDR 버전 + DIMM 종류 | MT/s, ECC, Rank, P/N | 추후 |
| NIC | 포트당 속도 + 포트 수 + 커넥터 | PCIe/OCP 규격, P/N | 추후 |
| GPU | 제조사 + 모델 + VRAM 용량 | 슬롯 크기, 전력 | 추후 |
| PSU | 출력 + P/N | AC/DC, 호환 서버 | 추후 |
| HBA·RAID | 제조사 + 모델 + 인터페이스 | 속도, 포트 수, 캐시, P/N | 추후 |
| 네트워크 장비 | 제조사 + 모델 | 포트 구성, PoE, 풍향 | 추후 |
| 서버 | 제조사 + 모델 | CPU·메모리·베이 구성 | 추후 |
| 기타 | 유형 | 사양 확정 후 별도 기준 정의 | 추후 |

## SSD·HDD 도입

전체 재고 화면은 `유형 + Site + SSD·HDD 사양`별로 행을 표시한다. SSD·HDD 외 유형은 기존 `유형 + Site` 집계를 유지한다. Site·유형 필터와 상태별 수량 열을 제공한다. 상태는 그룹 키에 넣지 않고 사용 가능·사용 중·장애·폐기 등으로 센다. 별도의 상태 선택 필터는 이번 범위에 포함하지 않는다.

SSD·HDD 집계에는 `specifications.capacity`, `interface`, `disk_size`를 사용한다.

| 규칙 | 처리 |
|---|---|
| 용량 단위 | 저장값은 보존하고 집계 시 십진 단위 `1 TB = 1000 GB`로 비교한다. |
| 같은 용량 | `1.92 TB`와 `1920 GB`, `1 TB`와 `1000 GB`는 같은 용량으로 묶는다. |
| 표시 | 1000 GB 이상은 TB, 미만은 GB로 표시한다. 부동소수점 오차 없이 십진수로 비교한다. |
| 인터페이스·폼팩터 | 저장된 선택값이 같아야 묶는다. `U.2`와 `2.5인치`를 임의로 동일시하지 않는다. |
| 불완전한 사양 | 세 항목 중 하나라도 없거나 폼팩터가 `기타`이면 Site별 `사양 미입력` 그룹으로 분리한다. 알려진 사양의 그룹에 추정 편입하지 않는다. |
| 상태·합계 | 기존 상태 분류를 유지하며, 그룹 분할 전후 전체 수량은 같다. `정상 재고`는 기존 정의인 장애·폐기 제외 수량이다. |
| 자산 보기 | 선택한 Site·유형·SSD·HDD 사양 그룹에 속한 개별 자산만 표시한다. |

예: IDC에 `1.92 TB / SAS / 2.5인치` 사용 가능 2개와 사용 중 1개가 있으면 한 행으로 표시한다. 같은 사양의 Office 자산은 별도 행이다. `SATA` 제품이나 `3.5인치` 제품은 다른 그룹이다. HDD 예시는 `4 TB / SATA / 3.5인치`이다. SSD와 HDD는 사양이 같아도 별도로 집계한다. HDD 회전수(RPM)는 이번 집계 기준에 포함하지 않는다.

## API와 확장

`GET /api/inventory/summary?group_by=specification`은 SSD·HDD 사양별 집계를 반환한다. 기본 호출과 `group_by=type`은 기존 유형·Site 집계를 유지한다. SSD·HDD 행의 `group_key`는 클라이언트가 해석하지 않고 `GET /api/assets?asset_type=SSD&site_type=IDC&group_key=...`에 그대로 전달한다. 요약과 자산 목록은 동일한 집계 키 함수를 사용한다.

다른 유형은 필수 사양·단위·누락값 처리 기준을 먼저 확정한 뒤 확대한다. P/N별 세분화와 상태 선택 필터는 후속 기능이다.
