# 서버 ID는 SRV 접두어를 사용한다

2026-09-27 변경: 신규 서버 라벨의 접두어는 `SVR-`, 네트워크 장비는 `NET-`을 사용한다. 기존 `SRV-` 식별자와 이력은 보존하고 계속 인식한다. 아래는 최초 결정의 배경이다.

일반 자산과 장착 대상인 서버를 현장에서 즉시 구분하기 위해 일반 자산은 `ASSET-`, 서버는 `SRV-` 접두어와 독립된 순번을 사용한다. 두 식별자는 동일한 재고 원장에서 관리하며, 기존 `ASSET-` SERVER는 이력의 식별자를 바꾸지 않기 위해 레거시 ID로 보존한다.
